\begin{prove}[Reflection]
  \begin{singlefigure}[光的反射]{chapter9_光的反射}[0.7]
  \end{singlefigure}
  如上图所示，由于介质相同，我们仅考虑最短距离。我们知道光必然经过镜面，因此总距离可以写为：
  \[L = \sqrt{a^2 + x^2}+ \sqrt{b^2 + (d-x)^2}\]

  根据费马原理，这个距离在真实光路时应该为极值，因此：
  \[\dfrac{\dif L}{\dif x} = 0\quad\Rightarrow\quad \dfrac{x}{\sqrt{a^2 + x^2}} - \dfrac{d-x}{\sqrt{b^2 + (d-x)^2}} = 0\]

  化简后可得：
  \[\sin \theta_1 = \sin \theta_2\]
  
  即：
  \[\theta_1 = \theta_2\]
\end{prove}

\begin{prove}[Refraction]
  \begin{singlefigure}[光的折射]{chapter9_光的折射}[0.6]
  \end{singlefigure}
  先写出光程的表达式，为：
  \[L = n_1\sqrt{a^2 + x^2}+ n_2\sqrt{b^2 + (d-x)^2}\]

  根据费马原理，光程在真实光路时应该为极值，因此：
  \[\dfrac{\dif L}{\dif x} = 0\quad\Rightarrow\quad n_1\dfrac{x}{\sqrt{a^2 + x^2}} = n_2\dfrac{d-x}{\sqrt{b^2 + (d-x)^2}}\]
  
  化简后可得$n_1\sin \theta_1 = n_2\sin \theta_2$。
\end{prove}

\begin{prove}[棱镜顶角、最小偏向角与折射率的关系]
  \begin{singlefigure}[棱镜]{chapter9_棱镜}[0.6]
  \end{singlefigure}
  假定从空气中入射，根据几何关系，我们可以得到：
  \begin{align*}
    \sin i_1 = n\sin i_1'\\
    \sin i_2 = n\sin i_2'\\
    i_2 + i_2' = \alpha\\
    \delta = i_1 + i_1' - \alpha
  \end{align*}

  我们要得到$\delta$角最小值，那么可以对其求导，$i_1$或$i_1'$为自变量。此处取前者，因为$\alpha$为定值，求导得到：
  \[\dfrac{\dif \delta}{\dif i_1} = 1 + \dfrac{\dif i_1'}{\dif i_1}\]

  现在我们需要一个导数的关系，那么对前三项依次求导，得到：
  \[\cos i_1 = n\cos i_2\dif{i_2}\]
  \[\cos i_1' = n\cos i_2'\dif{i_2'}\]
  \[\dif{i_2} + \dif{i_2'} = 0\]

  根据后三个关系式可以得到：
  \[\dfrac{\dif i_1'}{\dif i_1} = -\dfrac{\cos i_1\cos i_2'}{\cos i_1'\cos i_2}\]

  结合求导得到的关系式，由于每个角度都是小于$\pi/2$，并且满足联立得到的对称条件，那么当出现最小偏向角时，入射角和反射角分别对应相等，且:
  \[i_1 = i_1' = \dfrac{\delta +\alpha}{2}\qquad i_2 = i_2' = \dfrac{\alpha}{2}\]

  因此：
  \[n = \dfrac{\sin(\dfrac{\delta +\alpha}{2})}{\sin(\alpha/2)}\]
\end{prove}

\begin{prove}[球面透镜的成像规律]
  \begin{singlefigure}[球面透镜]{chapter9_球面透镜}[0.8]
  \end{singlefigure}

  我们先从一般情况出发，在$\Delta MQC$和$\Delta MQ'C$中应用正弦定理，可得：
  \[\dfrac{p}{\sin \phi} = \dfrac{o + r}{\sin \theta} = \dfrac{r}{\sin u}\]
  \[\dfrac{p'}{\sin \phi} = \dfrac{i - r}{\sin \theta'} = \dfrac{r}{\sin u'}\]

  两式相除，得到：
  \[\dfrac{p}{p'} = \dfrac{(o+r)\sin \theta'}{(i-r)\sin \theta} = \dfrac{(o+r)n}{(i-r)n'}\]

  再在两个三角形中应用余弦定理，得到：
  \[p^2 = r^2 + (o+r)^2 - 2r(o+r)\cos\phi = o^2 + 4r(o+r)\sin^2\dfrac{\phi}{2}\]
  \[p'^2 = r^2 + (i-r)^2 + 2r(i-r)\cos\phi = i^2 - 4r(i-r)\sin^2\dfrac{\phi}{2}\]

  两式相除，联立前面的$p - p'$关系式，可得：
  \[\dfrac{o^2 + 4r(o+r)\sin^2\dfrac{\phi}{2}}{i^2 - 4r(i-r)\sin^2\dfrac{\phi}{2}} = \dfrac{(o+r)^2 n^2}{(i-r)^2 n'^2}\]

  化简得到：
  \[\dfrac{o^2}{(o+r)^2 n^2} - \dfrac{i^2}{(i-r)^2 n'^2} = -4r\sin^2\dfrac{\phi}{2}\left[\dfrac{1}{(o+r)n^2} + \dfrac{1}{(i-r)n'^2}\right]\]

  可以看到$o$和$i$的取值与$\phi$有关，也就是说Q点发射的光无法一定到达我们理想的Q'点。如果不做近似，那么单个球面透镜无法对任意一点成像。当然也有一个特例，那就是等式两边同时取到0的时候，物距和像距的取值便与$\phi$无关，此时对应唯一的一组Q和Q'，其被称为齐明点。

  一般情况下球面镜成像需要满足傍轴近似，即$\phi\rightarrow 0$，此时$\sin^2\dfrac{\phi}{2} \approx 0$且$h \ll r$，上式可化简为：
  \[\dfrac{o^2}{(o+r)^2 n^2} = \dfrac{i^2}{(i-r)^2 n'^2}\]

  化简可得：
  \[\dfrac{n}{o} + \dfrac{n'}{i} = \dfrac{n'-n}{r}\]
  \tcbrule
  当然上面的推导可能比较繁琐，但我们已经知道公式的推导需要傍轴近似作为前提条件，那么满足$\phi$ 和$\theta$等角度都接近于0。另外，由图上的几何关系可知以下关系：
  \[\dfrac{r}{\sin u} = \dfrac{o+r}{\sin \theta}\qquad \dfrac{r}{\sin u'} = \dfrac{i-r}{\sin \theta'}\]
  \[n\sin\theta = n'\sin\theta'\qquad u+u' = \theta - \theta'\]

  傍轴近似下：
  \[\dfrac{r}{u} = \dfrac{o+r}{\theta}\qquad \dfrac{r}{u'} = \dfrac{i-r}{\theta'}\]
  \[n\theta = n'\theta'\qquad u+u' = \theta - \theta'\]

  联立消去$\theta$和$\theta'$，得到：
  \[i = r + \dfrac{n}{n'}\dfrac{u}{u'}(o+r)\]

  另外从图中可得$h = ou = iu'$，代入得到结果：
  \[\dfrac{n}{o} + \dfrac{n'}{i} = \dfrac{n'-n}{r}\]
\end{prove}

\begin{prove}[球面反射镜的成像规律]
  \begin{singlefigure}[球面反射镜]{chapter9_球面反射镜}[0.8]
  \end{singlefigure}

  我们可以直接代入上面求解得到的透镜折射公式，但由于反射镜本身是虚像，而我们图中表示的是正距离，因此像距为$-i$，且折射率$n' = -n$，因此：
  \[\dfrac{n}{o} + \dfrac{-n}{-i} = \dfrac{-n-n}{r} = -\dfrac{2}{r}\]

  分别取物距和像距到无穷大，则物像焦距为：
  \[f = -\dfrac{r}{2}\qquad f' = \dfrac{r}{2}\]

  这里的负号仅仅对应我们先前统一的正负号表达含义，不影响大小。
  \tcbrule

  或者我们也可以从几何的角度分析，同样也需要一些近似。
  
  由角度关系：
  \[\beta = \alpha + \theta \qquad \gamma = \alpha + 2\theta \qquad \alpha + \gamma = 2\beta\]

  由弧长公式结合一定的近似，有：
  \[\alpha\approx\dfrac{\overset{\Large{\frown}}{S}}{o}\qquad \beta = \dfrac{\overset{\Large{\frown}}{S}}{r}\qquad \gamma\approx\dfrac{\overset{\Large{\frown}}{S}}{i}\]

  因此可以得到一个和上面的推导仅仅相差一个负号的表达式：
  \[\dfrac{1}{o} + \dfrac{1}{i} = \dfrac{2}{r}\]
\end{prove}

\begin{prove}[\itr{Lens maker’s equation}{磨镜者公式}]
  \begin{singlefigure}[薄透镜成像]{chapter9_薄透镜成像}[0.9]
  \end{singlefigure}

  对于面$\Sigma_1$，有：
  \[\dfrac{f_1}{o_1} + \dfrac{f'_1}{i_1} = 1\]
  \[f_1 = \dfrac{nr_1}{n_L - n}\]
  \[f'_1 = \dfrac{n_L r_1}{n_L - n}\]

  对于面$\Sigma_2$，有：
  \[\dfrac{f_2}{o_2} + \dfrac{f'_2}{i_2} = 1\]
  \[f_2 = \dfrac{n_L r_2}{n' - n_L}\]
  \[f'_2 = \dfrac{n' r_2}{n' - n_L}\]

  其中第一个透镜的像即为第二个镜的物，满足以下关系：
  \[i_1 = -o_2 + d\approx -o_2\]

  把两个面看做一个整体，取物距为$o_1$，像距为$i_2$，消去$o_2$、$i_2$，并按照透镜成像的形式化简得到：
  \[\dfrac{f_1f_2}{o} + \dfrac{f'_1f'_2}{i} = f'_1 + f_2\]

  因此物方焦距：
  \[f = \dfrac{f_1f_2}{f'_1 + f_2} = \dfrac{nr_1 r_2}{(n'-n_L)r_1 + (n_L - n)r_2}\]

  像方焦距：
  \[f' = \dfrac{f'_1f'_2}{f'_1 + f_2} = \dfrac{n'r_1 r_2}{(n'-n_L)r_1 + (n_L - n)r_2}\]

  如果透镜两侧均为空气，即$n = n' = 1$，则：
  \[f = f' = \dfrac{1}{(n_L - 1)(\dfrac{1}{r_1} - \dfrac{1}{r_2})}\]
\end{prove}

\begin{prove}[\itr{Double-Slit Interference}{双缝干涉}]
  \begin{singlefigure}[双缝干涉]{chapter9_双缝干涉}[0.8]
  \end{singlefigure}
  我们已经得到两个波的叠加结果为：
  \[I(P) = 4I_1\cos^2(\dfrac{\varphi_1(P) - \varphi_2(P)}{2})\]

  从图中可知，两个点射出的光的相位差为：
  \[\varphi_1(P) - \varphi_2(P) = \dfrac{2\pi}{\lambda}(r_1 - r_2)\]

  当$L \gg d$时，可以得到光程差为：
  \[r_1 - r_2 = d\sin\theta \approx d\dfrac{y}{L}\]

  因此可知光强按照$\cos^2(\dfrac{\pi d y}{\lambda L})$在屏幕上变化。因此可得：
  \[y = \begin{cases}
        \dfrac{L}{d}m\lambda \quad \text{m为整数} & \text{明纹}\\[1em]
        \dfrac{L}{d}(m+\dfrac{1}{2})\lambda \quad \text{m为整数} \quad & \text{暗纹}
  \end{cases}\]
\end{prove}

\begin{prove}[\itr{Half-Wave Loss of Reflecting Light}{反射光的半波损失}]
  对于空间中任意的平面电磁波，其可以分解为垂直于该平面的分量与在该平面内的分量，我们分别称他们是s波和p波。
  
  当电场取s波时：
  \begin{singlefigure}[电场s波的情况]{chapter9_电场s波的情况}[0.7]
  \end{singlefigure}

  三个电场的表达式可写为：
  \[\vec{E}_{1,s} = \vec{a}_y E_{1,s} e^{i\vec{k}\cdot\vec{r}} = \vec{a}_y E_{1,s} e^{i(k_{1,s}\sin\theta_1 \hat{x} + k_{1,s}\cos\theta_1 \hat{z})}\]
  \[\vec{E'}_{1,s} = \vec{a}_y E'_{1,s} e^{i\vec{k}\cdot\vec{r}} = \vec{a}_y E'_{1,s} e^{i(k'_{1,s}\sin\theta'_1 \hat{x} - k'_{1,s}\cos\theta'_1 \hat{z})}\]
  \[\vec{E}_{2,s} = \vec{a}_y E_{2,s} e^{i\vec{k}\cdot\vec{r}} = \vec{a}_y E_{2,s} e^{i(k_{2,s}\sin\theta_2 \hat{x} + k_{2,s}\cos\theta_2 \hat{z})}\]
  
  根据电磁波的速度$v = \dfrac{1}{\sqrt{\varepsilon\mu}}$、关系式$E = vB$、$B = \mu H$，可得：
  \[H = \sqrt{\dfrac{\varepsilon}{\mu}}E\]

  因此可以得到三个磁场的表达式：
  \[\vec{H}_{1,s} = (-\vec{a}_x\sqrt{\dfrac{\varepsilon_1}{\mu_1}}E_{1,s}\cos\theta_1 + \vec{a}_z\sqrt{\dfrac{\varepsilon_1}{\mu_1}}E_{1,s}\sin\theta_1) e^{i(k_{1,s}\sin\theta_1 \hat{x} + k_{1,s}\cos\theta_1 \hat{z})}\]
  \[\vec{H'}_{1,s} = (\vec{a}_x\sqrt{\dfrac{\varepsilon_1}{\mu_1}}E'_{1,s}\cos\theta'_1 + \vec{a}_z\sqrt{\dfrac{\varepsilon_1}{\mu_1}}E'_{1,s}\sin\theta'_1) e^{i(k'_{1,s}\sin\theta'_1 \hat{x} - k'_{1,s}\cos\theta'_1 \hat{z})}\]
  \[\vec{H}_{2,s} = (-\vec{a}_x\sqrt{\dfrac{\varepsilon_2}{\mu_2}}E_{2,s}\cos\theta_2 + \vec{a}_z\sqrt{\dfrac{\varepsilon_2}{\mu_2}}E_{2,s}\sin\theta_2) e^{i(k_{2,s}\sin\theta_2 \hat{x} + k_{2,s}\cos\theta_2 \hat{z})}\]

  在交界面处，我们划定一个很薄的矩形，取其环路，根据麦克斯韦方程组要求，有$\oint \vec{E}\cdot d\vec{l} = -\iint\dfrac{\partial \vec{B}}{\partial t}\cdot\dif{\vec{S}}$，因为可以无限薄，所以可知电场应当满足连续性条件；同理，$\oint \vec{H}\cdot d\vec{l} = \iint\dfrac{\partial \vec{D}}{\partial t}\cdot\dif{\vec{S}}$，磁场也应当满足连续性条件。取$z = 0$，可得：
  \begin{align*}
    \begin{cases}
      E_{1,s} e^{ik_{1,s}\sin\theta_1\hat{x}} + E'_{1,s} e^{ik'_{1,s}\sin\theta'_1\hat{x}} = E_{2,s} e^{ik_{2,s}\sin\theta_2\hat{x}}\\
      -\sqrt{\dfrac{\varepsilon_1}{\mu_1}}E_{1,s}\cos\theta_1 e^{ik_{1,s}\sin\theta_1\hat{x}} + \sqrt{\dfrac{\varepsilon_1}{\mu_1}}E'_{1,s}\cos\theta'_1 e^{ik'_{1,s}\sin\theta'_1\hat{x}}\\
      \hspace{12em} = -\sqrt{\dfrac{\varepsilon_2}{\mu_2}}E_{2,s}\cos\theta_2 e^{ik_{2,s}\sin\theta_2\hat{x}}
    \end{cases}
  \end{align*}

  注意到，这两个等式应当对任意的$x$均成立，对于复指数而言，要求指数部分完全一致才可以满足，因此：
  \[k'_1\sin\theta_1 = k'_{1,s}\sin\theta'_1 = k_{2,s}\sin\theta_2\]

  由振动与波的要求，$k = \dfrac{2\pi n}{\lambda}$，这可以得到几何光学的反射和折射定律$\theta_1 = \theta'_1$以及$n_1\sin\theta_1 = n_2\sin\theta_2$。

  因此可以约去一些不必要的部分，得到简化的方程组：
  \begin{align*}
    \begin{cases}
      E_{1,s} + E'_{1,s} = E_{2,s}\\
      -\sqrt{\dfrac{\varepsilon_1}{\mu_1}}E_{1,s}\cos\theta_1 + \sqrt{\dfrac{\varepsilon_1}{\mu_1}}E'_{1,s}\cos\theta'_1 = -\sqrt{\dfrac{\varepsilon_2}{\mu_2}}E_{2,s}\cos\theta_2
    \end{cases}
  \end{align*}

  在光学中，各个介质的磁导率近似相等且近似于1，介电常数可以近似表示为：
  \[\sqrt{\varepsilon_1} \approx n_1\sqrt{\varepsilon_0}\qquad\sqrt{\varepsilon_2} \approx n_2\sqrt{\varepsilon_0}\]

  进一步得到更加简化的方程组：
  \begin{align*}
    \begin{cases}
      E_{1,s} + E'_{1,s} = E_{2,s}\\
      -n_1 E_{1,s}\cos\theta_1 + n_1 E'_{1,s}\cos\theta'_1 = -n_2 E_{2,s}\cos\theta_2
    \end{cases}
  \end{align*}

  定义反射系数$r_s = \dfrac{E'_{1,s}}{E_{1,s}}$和透射系数$t_s = \dfrac{E_{2,s}}{E_{1,s}}$，根据方程组可解得：
  \[r_s = \dfrac{n_1\cos\theta_1 - n_2\cos\theta_2}{n_1\cos\theta_1 + n_2\cos\theta_2} = \dfrac{\sin\theta_2\cos\theta_1 - \sin\theta_1\cos\theta_2}{\sin\theta_2\cos\theta_1 + \sin\theta_1\cos\theta_2} = \dfrac{\sin(\theta_2 - \theta_1)}{\sin(\theta_2 + \theta_1)}\]
  \[t_s = 1 + r_s = \dfrac{2n_1\cos\theta_1}{n_1\cos\theta_1 + n_2\cos\theta_2}\]

  若为正入射的情况，$r_s = \dfrac{n_1 - n_2}{n_1 + n_2}$，因此$n_1 < n_2$时$r_s < 0$，因此入射电场与反射电场相差相位$\pi$，即有半波损失。否则没有半波损失。

  当电场取p波时：
  \begin{singlefigure}[电场p波的情况]{chapter9_电场p波的情况}[0.7]
  \end{singlefigure}
  
  同理，我们可以得到以下关于电场和磁场的方程：
  \[\vec{E}_{1,p} = (\vec{a}_x E_{1,p} \cos\theta_1 - \vec{a}_z E{1,p}\sin\theta_1) e^{i(k_{1,p}\sin\theta_1 \hat{x} + k_{1,p}\cos\theta_1 \hat{z})}\]
  \[\vec{E'}_{1,p} = (-\vec{a}_x E'_{1,p} \cos\theta'_1 - \vec{a}_z E'_{1,p}\sin\theta'_1) e^{i(k'_{1,p}\sin\theta'_1 \hat{x} - k'_{1,p}\cos\theta'_1 \hat{z})}\]
  \[\vec{E}_{2,p} = (\vec{a}_x E_{2,p} \cos\theta_2 - \vec{a}_z E_{2,p}\sin\theta_2) e^{i(k_{2,p}\sin\theta_2 \hat{x} + k_{2,p}\cos\theta_2 \hat{z})}\]
  \[\vec{H}_{1,p} = \vec{a}_y \sqrt{\dfrac{\varepsilon_1}{\mu_1}} E_{1,p} e^{i(k_{1,p}\sin\theta_1 \hat{x} + k_{1,p}\cos\theta_1 \hat{z})}\]
  \[\vec{H'}_{1,p} = \vec{a}_y \sqrt{\dfrac{\varepsilon_1}{\mu_1}} E'_{1,p} e^{i(k'_{1,p}\sin\theta'_1 \hat{x} - k'_{1,p}\cos\theta'_1 \hat{z})}\]
  \[\vec{H}_{2,p} = \vec{a}_y \sqrt{\dfrac{\varepsilon_2}{\mu_2}} E_{2,p} e^{i(k_{2,p}\sin\theta_2 \hat{x} + k_{2,p}\cos\theta_2 \hat{z})}\]

  代入边界条件，同样的处理，可得：
  \begin{align*}
    \begin{cases}
      \theta_1 = \theta'_1\qquad n_1\sin\theta_1 = n_2\sin\theta_2\\
      E_{1,p}\cos\theta_1 - E'_{1,p}\cos\theta'_1 = E_{2,p}\cos\theta_2\\
      \sqrt{\dfrac{\varepsilon_1}{\mu_1}}E_{1,p} + \sqrt{\dfrac{\varepsilon_1}{\mu_1}}E'_{1,p} = \sqrt{\dfrac{\varepsilon_2}{\mu_2}}E_{2,p}\\
    \end{cases}
  \end{align*}

  即:
  \begin{align*}
    \begin{cases}
      (E_{1,p} - E'_{1,p})\cos\theta_1 = E_{2,p}\cos\theta_2\\
      n_1 E_{1,p} + n_1 E'_{1,p} = n_2 E_{2,p}
    \end{cases}
  \end{align*}

  采用同样的反射系数和透射系数定义，可得：
  \[r_p = \dfrac{E'_{1,p}}{E_{1,p}} = \dfrac{n_2\cos\theta_1 - n_1\cos\theta_2}{n_2\cos\theta_1 + n_1\cos\theta_2} = \dfrac{\tan(\theta_1 - \theta_2)}{\tan(\theta_1 + \theta_2)}\]
  \[t_p = \dfrac{2 n_1 \cos\theta_1}{n_2\cos\theta_1 + n_1\cos\theta_2}\]

  若为正入射的情况，$r_p = \dfrac{n_2 - n_1}{n_1 + n_2}$，$n_1 < n_2$时由于我们上图规定的电场起偏方向本身是相反的（考虑正入射时上图入射光电场向右，反射光电场向左），本身自带有一个负号，因此半波损失情况与$s$波时相同。

  综上，正入射的光当从$n_1$介质到$n_2$介质时，若$n_1 < n_2$则反射光有半波损失。同时可得透射光无半波损失。
\end{prove}

\begin{prove}[牛顿环的曲率半径]
  \begin{singlefigure}[牛顿环]{chapter9_牛顿环}[0.6]
  \end{singlefigure}
  根据几何关系可知：
  \[R^2 = (R - e_m)^2 + r_m^2\]

  因此：
  \[2Re_m = e_m^2 + r_m^2\]

  由于$e_m$很小，忽略其高阶项，得到：
  \[e_m = \dfrac{r_m^2}{2R}\]

  由于中间层为空气，需要考虑半波损失，并代入第$m$个暗环的方程：
  \[2e_m + \dfrac{\lambda}{2} = (m + \dfrac{1}{2})\lambda\]

  得到：
  \[R = \dfrac{r_m^2}{m\lambda}\]
\end{prove}

\begin{prove}[\itr{Multi-slit diffraction}{多缝衍射}]
  \begin{singlefigure}[多缝衍射]{chapter9_多缝衍射}[0.99]
  \end{singlefigure}

  我们仍然假设最上面一个点的相位为0，作为参考相位。根据单缝衍射的结论，每一个缝对应的电场结果为：
  \[E_{\theta} = E_0\dfrac{\sin\alpha}{\alpha}e^{i\alpha}\qquad \alpha = \dfrac{\pi}{\lambda}a\sin\theta\]

  由图可知，相邻两个缝的相位差为$\dfrac{2\pi}{\lambda}d\sin\theta$，假设一共$N$个缝，则：
  \begin{align*}
    E_1 &= E_{\theta} e^{i\cdot 0}\\
    E_2 &= E_{\theta} e^{i\cdot \frac{2\pi}{\lambda}\cdot d \sin \theta}\\
    E_3 &= E_{\theta} e^{i\cdot 2\cdot \frac{2\pi}{\lambda}\cdot 2d\sin \theta}\\
    &\cdots\\
    E_N &= E_{\theta} e^{i\cdot (N-1)\cdot \frac{2\pi}{\lambda}\cdot (N-1)d\sin \theta}
  \end{align*}

  对以上作级数求和，可得：
  \begin{align*}
    E &= \sum_{n=1}^{N}E_{\theta}e^{i(n-1)\frac{2\pi}{\lambda}d\sin\theta}\\
    &= E_{\theta}\dfrac{1-e^{i\frac{2\pi}{\lambda} Nd\sin\theta}}{1-e^{i\frac{2\pi}{\lambda} d\sin\theta}}\\
    &= E_{\theta}\dfrac{(e^{-i\frac{\pi}{\lambda} Nd\sin\theta}- e^{i\frac{\pi}{\lambda} Nd\sin\theta})e^{i\frac{\pi}{\lambda} Nd\sin\theta}}{(e^{-i\frac{\pi}{\lambda} d\sin\theta}-e^{i\frac{\pi}{\lambda} d\sin\theta})e^{i\frac{\pi}{\lambda} d\sin\theta}}\\
    &= E_{\theta}\dfrac{-2i\sin(\frac{\pi}{\lambda}Nd\sin\theta)}{-2i\sin(\frac{\pi}{\lambda}d\sin\theta)}e^{i(N-1)\frac{\pi}{\lambda}d\sin\theta}
  \end{align*}

  令$\beta = \dfrac{\pi}{\lambda}d\sin\theta$，则：
  \[E = E_{\theta}\dfrac{\sin(N\beta)}{\sin(\beta)}e^{i(N-1)\beta} = E_0\dfrac{\sin\alpha}{\alpha}e^{i\alpha}\dfrac{\sin(N\beta)}{\sin(\beta)}e^{i(N-1)\beta}\]
\end{prove}

\begin{prove}[\itr{Resolving power of diffraction grating}{光栅的分辨能力}]
  根据正文部分的推导，多缝衍射主极大的半角宽度$\Delta\theta$可以如下表示：
  \[\Delta\theta = \dfrac{\lambda}{Nd\cos\theta}\]

  根据光栅方程的结论：
  \[\dfrac{\Delta\theta}{\Delta\lambda} = \dfrac{m}{d\cos\theta}\]

  代入，整理，可得：
  \[\dfrac{\lambda}{Nd\cos\theta\Delta\lambda} = \dfrac{m}{d\cos\theta}\]

  因此：
  \[A = \dfrac{\lambda}{\Delta\lambda} = mN\]
\end{prove}

\begin{prove}[\itr{Brewster’s angle}{布儒斯特角}]
  与上面半波损失相关的推导一致，假设s波电场垂直纸面，p波电场平行于纸面。任意表示光的电场矢量可以被分解为s波和p波两个分量。另外我们也得到如下结果：
  \[r_s = \dfrac{n_1\cos\theta_1 - n_2\cos\theta_2}{n_1\cos\theta_1 + n_2\cos\theta_2} = \dfrac{\sin(\theta_2 - \theta_1)}{\sin(\theta_2 + \theta_1)}\]
  \[t_s = 1 + r_s = \dfrac{2n_1\cos\theta_1}{n_1\cos\theta_1 + n_2\cos\theta_2}\]
  \[r_p = \dfrac{n_2\cos\theta_1 - n_1\cos\theta_2}{n_2\cos\theta_1 + n_1\cos\theta_2} = \dfrac{\tan(\theta_1 - \theta_2)}{\tan(\theta_1 + \theta_2)}\]
  \[t_p = \dfrac{2 n_1 \cos\theta_1}{n_2\cos\theta_1 + n_1\cos\theta_2}\]

  考虑反射系数，可以发现，当$\theta_1 + \theta_2 = \pi$时，反射系数$r_p$趋于0，即反射光的p波分量的强度反射率$R_p = |r_p|^2 = 0$。表明此时p波没有被反射的部分，即出现布儒斯特角。

  同样我们可以得知，s波同时存在被反射和透射的部分，因此反射波的偏振方向仅含p波分量，而折射光同时存在两个方向的偏振态。
\end{prove}
